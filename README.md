# brightsmile

BrightSmile Dental Clinic — a multi-page static website (HTML, CSS, JavaScript).

## Pages

- `index.html` — Home
- `about.html` — About & team
- `services.html` — Services, process & FAQ
- `advanced-care.html` — Technology & safety
- `testimonials.html` — Reviews & smile gallery
- `contact.html` — Appointment form, hours & map

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx http-server -p 5500
```

## Editing clinic details

Phone, WhatsApp, email, address and hours are set once in the `CLINIC` object at the top of `js/main.js`.
